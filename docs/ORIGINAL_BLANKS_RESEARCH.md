Репозиторий: `metr-cabinet` · приложение: `psycho-app` (49 шкал)

## Статус внедрения (свободные)

Подключены как **официальные свободные формы** при печати:

`phq9`, `gad7`, `audit`, `pcl5`, `asq`, `asrs`, `ace`, `stopbang`, `whodas`, `aq10`

- Печать: HTML в официальной вёрстке + attribution + ФИО специалиста внизу (в пакете — под каждым).
- PDF-эталоны (только русский) в `psycho-app/public/original-blanks/`: PHQ-9, AUDIT.
- Реестр: `psycho-app/src/data/freeBlanks.ts`.
- Английские PDF не подключаются.

Коммерческие (BDI, HADS, MoCA, DIVA, SCL-90-R…) по-прежнему только рабочие HTML — без издательских PDF.

## 1. Что есть сейчас

Приложение для большинства шкал печатает HTML из `blank.ts`.  
Для списка свободных — отдельный официальный шаблон (`lib/officialBlank.ts`).

Внизу каждого бланка — дата и выбранный специалист.

## 2. Что значит «оригинальный бланк»

Обычно это одно из трёх:

| Вариант | Суть | Плюсы | Минусы |
|--------|------|-------|--------|
| **A. Официальный PDF** | Печать файла издателя / автора (как в клинике) | Максимально «как принято» | Нужны права; PDF не всегда на русском; сложно вшить в пакет печати |
| **B. Верная копия** | Наш HTML/PDF строго по официальному тексту, шкале и разметке | Удобно в текущем UI | Для защищённых шкал — нужна лицензия / нельзя класть в публичный репо |
| **C. Как сейчас** | Рабочий бланк «по смыслу» | Уже есть | Не оригинал по вёрстке и иногда по формулировкам |

Для приёма обычно нужен **A** (где можно) или **B с лицензией**.

## 4. Технические варианты внедрения в МЕТР

### Вариант 1 — «Печать оригинала» для свободных шкал (рекомендуемый первый шаг)

1. Папка `psycho-app/public/original-blanks/` (или вне git + локальные файлы).
2. В метаданных теста: `originalBlankUrl` / `originalBlankFile` + `blankSource: 'generated' | 'original-pdf'`.
3. Кнопка «Печать бланка»:
   - если есть оригинал → открыть/печатать PDF;
   - иначе → текущий HTML.
4. В пакетной печати: для PDF — отдельные страницы `iframe`/`embed` или предварительный merge; для HTML — как сейчас.
5. Футер специалиста на **официальном PDF** издателя обычно **нельзя менять**. Варианты:
   - печатать PDF как есть + отдельный лист-сопроводитель с ФИО специалиста;
   - или поверх PDF только если лицензия позволяет (редко).

### Вариант 2 — Локальная библиотека бланков (для вашего кабинета)

Вы храните купленные/полученные PDF **локально** (не в публичном GitHub).  
Приложение читает их с диска / из приватного хранилища.  
Подходит для BDI, HADS, MoCA, DIVA и т.д. после вашей лицензии.

### Вариант 3 — Только улучшить HTML «как оригинал»

Довести вёрстку/формулировки к официальным **где это разрешено** (PHQ/GAD и т.п.).  
Для Pearson/HADS — не копировать оригинальную вёрстку без лицензии.

## 5. Предлагаемый порядок работ

1. **Решить модель:** публичный GitHub Pages vs только локальный кабинет.  
   На Pages безопасно выкладывать только **группу 1** (и то — официальные файлы с сайта авторов, с attribution).
2. **Пилот (группа 1):** PHQ-9, GAD-7, PCL-5, AUDIT, ASQ — скачать русские официальные PDF, подключить печать.
3. **MoCA / DIVA:** вы оформляете доступ → кладёте PDF в приватное место → подключаем печать по пути.
4. **Pearson / HADS / MMSE:** либо оставить рабочие HTML, либо печать только с ваших лицензионных бланков локально.
5. **Специалист на бланке:** для HTML — как сейчас; для чужих PDF — сопроводитель или штамп только если разрешено.
