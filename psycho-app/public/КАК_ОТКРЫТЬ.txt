МЕТР — расчёт шкал и бланки
===========================

На работу по почте:
• Файл «Расчет тестов.zip» в корне проекта — скачайте/прикрепите к письму.
• На работе: распакуйте → откройте index.html (Chrome / Edge).

Как пользоваться:
1. Выберите тест слева → «Печать бланка» → пациент заполняет.
2. Введите ответы → «Рассчитать» → скопируйте сводку.

Доработка дома (нужен Node.js), папка psycho-app:
  npm run build
обновляет папку «Расчет тестов» и файл «Расчет тестов.zip».
